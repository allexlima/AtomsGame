# Atoms Game - The Periodic Table Saga

Atoms Game is an educational game developed with JavaScript and HTML5, designed to help children and teenagers learn the Periodic Table of Elements.

## About the Project

This project was initially developed by a team of students from the Computation Department at UniNorte Laureate in Manaus, Brazil. It was presented at the National Institute of Amazonian Research (INPA) to teachers and students from public schools.

The goal is to contribute to chemistry education through engaging digital experiences.

## How to Play

1.  Open the game in your browser (preferably Google Chrome on a desktop computer).
2.  The game works best in landscape mode.
3.  Click "Play" to start.
4.  An element name will appear on the left.
5.  Elements will fall from the top of the screen.
6.  Click on the falling element that matches the name shown.
7.  If you click the correct element, you score points.
8.  If you miss or click the wrong one, you lose a life.
